# 치지직 채팅 호출 알림 (CHZZK Alert)

## ⚡ 무지성 설치하기

설명은 읽지 말고 **1 → 2 → 3 순서대로** 누르기만 하세요. (자세한 설명은 아래 [1. 설치하기](#1-설치하기-처음이신-분은-여기부터))

1. **몽키 설치** 👉 [크롬](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) · [엣지](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
2. **사용자 스크립트 ON** 👉 아래 주소를 복사해서 **주소 입력칸에 붙여넣고 Enter** (크롬 기준, 엣지는 [자세히](#2단계-사용자-스크립트-허용-켜기-아주-중요))

   ```text
   chrome://extensions/?id=dhdgffkkebhmkfjojejmpbldmpobfkfo
   ```

   > ⚠️ 열리는 화면에서 **"사용자 스크립트 허용"을 반드시 ON 하세요.** (`chrome://` 주소는 보안상 클릭으로 열 수 없어서 복사해서 붙여넣어야 합니다)
3. **스크립트 적용** 👉 [여기를 눌러 설치](https://raw.githubusercontent.com/Dark1004-K/Chzzk_Alert/main/chzzk_alert.user.js) → 열린 화면에서 **`설치`** 버튼

끝나면 치지직 방송 화면을 **새로고침(F5)** 하세요. 🎉

---

> **업데이트 내용 보러가기 → 정식: [UPDATE.md](./UPDATE.md) · 베타: [beta/UPDATE.md](./beta/UPDATE.md)**

치지직(CHZZK) 생방송 채팅에서 **내가 등록한 단어(닉네임 등)가 나오면** 알려주는 프로그램입니다.
방송을 보다가 다른 창을 보고 있어도, 누가 나를 불렀는지 놓치지 않게 해줍니다.

* 채팅에서 내 이름이 불리면 → **알림창 + 화면 안내문 + 알림음**
* 불린 대화가 목록에 쌓이고, 누르면 그 채팅으로 이동
* 방송에 **드롭스**가 있으면 내 시청 시간과 보상을 보여주고, 시간이 차면 알려줌
* **확장(플러그인)** 으로 호출 음성 안내(TTS), 검은사막 우두머리 시간 알림 등을 켜고 끔

> 새 기능을 먼저 써보고 싶으면 **베타 버전**도 있습니다. 설치 방법은 문서 맨 아래 [부록 A](#부록-a-베타-버전-설치)에 있습니다.

## 1. 설치하기 (처음이신 분은 여기부터)

컴퓨터를 잘 몰라도 **아래 순서를 위에서부터 하나씩** 따라 하면 됩니다.
전체 시간은 5분 정도 걸립니다. 모르는 단어가 나와도 괄호 안 설명만 따라 하세요.

### 0단계. 먼저 확인하세요

| 확인할 것 | 설명 |
| --- | --- |
| **컴퓨터(PC)** 인가요? | 휴대폰·태블릿에서는 쓸 수 없습니다. 윈도우 PC나 맥에서 사용하세요. |
| 어떤 **인터넷 창(브라우저)** 을 쓰세요? | **크롬(Chrome)**, **엣지(Edge)**, **웨일(Whale)** 중 하나면 됩니다. 이 문서는 크롬 기준이고, 엣지·웨일도 화면 모양만 조금 다를 뿐 똑같습니다. |
| **치지직에 로그인**하셨나요? | 치지직에 로그인되어 있어야 동작합니다. 로그인이 안 되어 있으면 아무것도 뜨지 않습니다. |
| **등록된 채널**인가요? | 지금은 등록된 방송 채널에서만 동작합니다. 등록되지 않은 방송에서는 `인가되지 않은 채널입니다`라는 안내가 뜹니다. 등록은 [5. 채널 추가 요청](#5-채널-추가-요청)을 보세요. |

### 1단계. Tampermonkey(탬퍼몽키) 설치

> **Tampermonkey란?** 인터넷 창에 작은 프로그램을 붙여주는 "도구"입니다.
> 우리 프로그램은 이 도구 위에서 돌아가기 때문에, **먼저 이 도구부터 설치**해야 합니다.

1. 쓰시는 인터넷 창에 맞는 아래 링크를 **클릭**합니다. (새 탭에서 열립니다)
   * 크롬: [Tampermonkey - Chrome 웹 스토어](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   * 엣지: [Tampermonkey - Edge 추가 기능](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
   * 웨일: 웨일 주소창 옆 확장 스토어에서 `Tampermonkey`를 검색
2. 열린 화면 오른쪽 위쪽의 **파란색 `Chrome에 추가`** 버튼을 누릅니다.
   (엣지는 `가져오기`, 웨일은 `웨일에 추가`)
3. 가운데에 작은 창이 뜨며 **"Tampermonkey을(를) 추가하시겠습니까?"** 라고 물으면
   **`확장 프로그램 추가`** 를 누릅니다.
4. 잠시 뒤 오른쪽 위에 **"Tampermonkey이(가) 추가되었습니다"** 라는 말풍선이 뜨고,
   Tampermonkey 설명 탭이 새로 열리기도 합니다. 그러면 성공입니다. 열린 탭은 그냥 닫아도 됩니다.
5. **아이콘 고정하기 (꼭 하지 않아도 되지만 하면 편합니다)**
   * 인터넷 창 **오른쪽 위**에 있는 **퍼즐 조각 모양 아이콘 🧩** 을 누릅니다.
   * 목록에서 **Tampermonkey** 오른쪽의 **핀(📌) 모양**을 누릅니다.
   * 이제 오른쪽 위에 **검은 네모에 점 두 개** 모양의 Tampermonkey 아이콘이 계속 보입니다.

### 2단계. "사용자 스크립트 허용" 켜기 (아주 중요!)

> 이 단계를 건너뛰면 **채팅창을 접어두었을 때 호출을 못 잡거나, 확장(플러그인)이 동작하지 않습니다.**
> 컴퓨터가 처음이시면 천천히, 아래 그대로 따라 하세요.

#### ⚡ 가장 빠른 방법 (추천)

아래 주소를 **복사**해서 인터넷 창 **맨 위의 주소 입력칸에 붙여넣고 Enter** 키를 누르세요.
Tampermonkey의 **세부정보 화면이 바로 열립니다.** (코드 블록 오른쪽 위의 복사 버튼을 누르면 편합니다)

* 크롬

```text
chrome://extensions/?id=dhdgffkkebhmkfjojejmpbldmpobfkfo
```

* 엣지

```text
edge://extensions/?id=iikmkjmpaadaobahmlepeloendndfphd
```

화면이 열리면 아래 **5번**(`사용자 스크립트 허용` 스위치 켜기)으로 바로 가세요.

> ℹ️ `chrome://` 주소는 보안상 웹페이지(이 문서 포함)에서 **클릭해서 열 수 없습니다.** 꼭 복사해서 주소 입력칸에 붙여넣어야 합니다.
> 웨일은 주소가 달라서 아래 일반 방법을 따라 하세요.

#### 일반 방법 (위 방법이 안 될 때)

1. 인터넷 창 **맨 위의 주소 입력칸**(`https://...`이 적혀 있는 곳)을 한 번 클릭합니다.
2. 안에 있던 글자를 모두 지우고 아래 글자를 **그대로** 입력(또는 복사해서 붙여넣기)한 뒤 **Enter** 키를 누릅니다.
   * 크롬: `chrome://extensions`
   * 엣지: `edge://extensions`
   * 웨일: `whale://extensions`
3. **"확장 프로그램"** 이라는 제목의 화면이 열립니다. 카드(네모 칸)들이 보이는데, 그중 **Tampermonkey** 카드를 찾습니다.
4. 그 카드 아래쪽의 **`세부정보`** 버튼을 누릅니다.
5. 열린 화면을 **아래로 스크롤**하면서 **`사용자 스크립트 허용`** 이라는 항목을 찾아, 오른쪽의 **스위치(토글)를 눌러 켭니다.**
   * 켜지면 스위치가 **파란색(또는 오른쪽)** 으로 바뀝니다.
6. 만약 `사용자 스크립트 허용`이 안 보이면:
   * 같은 화면(확장 프로그램 목록) **오른쪽 위**의 **`개발자 모드`** 스위치를 켠 다음 3~5번을 다시 해보세요.
   * 브라우저 버전에 따라 이름이 `사용자 스크립트 허용` 대신 `개발자 모드` 하나로 되어 있는 곳도 있습니다.
     이 경우 **개발자 모드를 켜면** 됩니다.

> 💡 이 설정은 한 번만 하면 됩니다. 브라우저를 껐다 켜도 유지됩니다.

### 3단계. 호출 알림 프로그램 설치

1. 아래 **파란 글씨 링크를 클릭**합니다.
   * 👉 [정식 버전 설치 링크](https://raw.githubusercontent.com/Dark1004-K/Chzzk_Alert/main/chzzk_alert.user.js)
2. 잠시 뒤 **Tampermonkey 설치 화면**이 새 탭으로 열립니다.
   (`CHZZK 채팅 호출 알림`이라는 이름과 긴 설명이 보이는 화면입니다)
   * 이 화면이 안 뜨고 **글자만 잔뜩 보이면** 1·2단계가 덜 된 것입니다. 1단계 5번(아이콘이 보이는지)을 확인해 보세요.
3. 화면 **왼쪽 위의 `설치` 버튼**(또는 `Install`)을 누릅니다.
4. 설치가 끝나면 탭이 닫히거나 "설치됨"이라고 바뀝니다. 끝났습니다. 🎉

### 4단계. 잘 설치됐는지 확인

1. 오른쪽 위 **Tampermonkey 아이콘**을 누릅니다.
2. 목록에 **`CHZZK 채팅 호출 알림`** 이 보이고, 그 옆 스위치가 **켜져(초록색)** 있으면 정상입니다.
3. 이제 [2. 처음 사용하기](#2-처음-사용하기)로 가세요.

## 2. 처음 사용하기

### 2-1. 방송 열고 시작하기

1. 치지직(<https://chzzk.naver.com>)에 **로그인**합니다. (필수)
2. 등록된 채널의 **생방송 화면**을 엽니다. 이미 열려 있던 방송이면 **새로고침(키보드 F5)** 을 한 번 누르세요.
   (설치·업데이트 직후에는 **반드시** 새로고침해야 합니다)
3. 화면 **왼쪽 아래**에 알림창들이 생깁니다.
   * **초록 테두리 창**이 가장 아래에 있는 "감시중" 창입니다.
4. 처음에는 **`채팅 호출 알림을 켤까요?`** 라는 창이 뜹니다.
   * **`켜기`** 를 누릅니다.
   * `다음부터 묻지 않고 자동으로 켜기`에 체크해 두면 다음부터는 방송에 들어가면 바로 켜집니다.
   * 기본으로 **묻지 않고 자동으로 켜집니다.**
5. 브라우저 위쪽에 **"알림을 보내려고 합니다"** 같은 말이 뜨면 **`허용`** 을 누릅니다.
   (다른 창을 보고 있을 때도 알림이 오게 하기 위한 것입니다. `차단`을 누르면 화면 안내문과 소리만 납니다)

### 2-2. 내 이름(호출 단어) 등록하기

1. 초록 창 **오른쪽 위의 슬라이더 모양 아이콘 ⚙(설정)** 을 누릅니다.
2. 설정 창이 옆에 열리면 왼쪽의 **`단어설정`** 을 누릅니다.
3. **`추가할 단어`** 칸에 부를 때 쓰는 말(닉네임 등)을 쓰고 **`추가`** 를 누릅니다.
   * 여러 개를 등록할 수 있습니다. 잘못 넣었으면 단어 옆 **`×`** 를 누르면 지워집니다.
4. 맨 아래 **`내 닉네임`** 칸에는 **내 치지직 닉네임**을 적습니다.
   * 내가 쓴 채팅에는 알림이 울리지 않게 하는 칸입니다.
5. **더 쉬운 방법:** 방송 화면의 글자를 **마우스로 드래그해서 선택**하면 `＋ 호출 단어로 추가` 버튼이 뜹니다. 그걸 누르면 바로 등록됩니다.

### 2-3. 알림이 오는지 시험해 보기

* 채팅창에 내가 등록한 단어가 들어간 글이 올라오면 **알림창, 화면 안내문, 소리**가 나옵니다.
* 불린 대화는 **노란 테두리 창**에 쌓입니다. 누르면 그 채팅 위치로 이동합니다.
* 소리가 안 나면 [6. 문제가 생겼을 때](#6-문제가-생겼을-때)를 보세요.

## 3. 화면 설명과 설정

### 3-1. 화면 구성 (왼쪽 아래, 위에서 아래 순서)

| 순서 | 창 | 설명 |
| --- | --- | --- |
| 1 | 🟧 **드롭스** (주황) | 방송에 드롭스가 있을 때만 나타납니다. 보상 이름, 내 시청 시간, 새로고침🔄, 보관함📦 버튼. |
| 2 | 🟦 **다음 우두머리** (파랑) | `확장`에서 **검은사막**을 켰을 때만 나타납니다. 다음 우두머리와 남은 시간. |
| 3 | 🟨 **불린 대화** (노랑) | 호출된 대화 목록. 최대 30개 저장, 위가 오래된 것·아래가 최신. |
| 4 | 🟩 **감시중** (초록) | 지금 감시 중인지 표시. 단어 수, 정지▶/시작 버튼, 설정⚙, 채널 홈🏠·디스코드💬 버튼. |
| (옆) | ⬜ **설정** (회색) | 초록 창 오른쪽에 열리는 설정 창. |

* 각 창(초록 메인 창 제외)의 **오른쪽 위 X 버튼**(창 색과 같은 색)을 누르면 그 창이 꺼집니다. 설정의 해당 체크를 끈 것과 같아서, 다시 켜려면 설정에서 체크하면 됩니다.
  (드롭스 → 일반설정의 "드롭스 보기", 불린 대화 → "불린 대화 목록 별도 표시", 다음 우두머리·쿠폰 → 확장의 검은사막 옵션. 설정 창의 X는 창 닫기입니다)

### 3-2. 창 크기 조절

* **너비**: 초록 창 **오른쪽 아래 원(↔)** 을 잡고 좌우로 끕니다. (225~600px)
* **불린 대화 높이**: 노란 창 **맨 위 가운데의 가로 막대(―)** 를 잡고 위로 끌면 길어지고 아래로 끌면 줄어듭니다.
  (최소 80px, 최대 화면 높이의 85%. 위의 창들이 화면 밖으로 넘치지 않도록 화면이 모자라면 이 목록이 먼저 줄어듭니다)
* 막대에 마우스를 올리면 색이 바뀌고 커서 모양이 화살표로 바뀝니다. 정한 크기는 저장됩니다.

### 3-3. 설정 창 안내

설정 창은 왼쪽 **탭 4개**로 나뉩니다.


* **설정 창 옮기기**: 설정 창 **왼쪽 위 모서리의 동그란 사방 화살표 아이콘**(또는 "설정" 글자)을 끌면 화면 아무 곳으로 옮길 수 있습니다. 화면 가장자리나 다른 창에 가까워지면 **자석처럼 붙고**(초록 테두리), 아이콘을 **더블클릭**하면 원래 자리로 돌아옵니다.

## 4. 기능 자세히 보기

### 4-1. 감지 규칙

* 등록한 단어가 채팅에 나오면 감지합니다. 대소문자는 구분하지 않고, 띄어쓰기 차이는 흡수합니다.
* **단어 경계 보호**: `데아`를 등록했을 때 `그런데 아~~`처럼 띄어쓰기 경계를 넘어 합쳐지는 경우는 제외합니다.
  같은 어절 안에 붙어 있는 경우(`데아님`, `데아!`)는 감지합니다.
* **내 채팅 제외**: `내 닉네임`에 적은 이름으로 쓴 내 채팅은 알림에서 뺍니다. 남이 내 닉네임을 부른 것은 정상 감지합니다.

### 4-2. 알림 3종

1. **브라우저 알림**: 제목에 부른 사람 닉네임, 본문에 대화 내용이 뜹니다. 직접 닫을 때까지 유지되고 누르면 방송 창으로 돌아옵니다.
   윈도우 기본 알림음은 끄고 아래 3번 소리만 냅니다.
2. **화면 안내문(토스트)**: 초록 창 **오른쪽**(설정 창이 열려 있으면 그 바로 위)에 5초간 떴다가 사라집니다. 글이 길면 줄이 바뀌어 세로로 늘어나고, 누르면 바로 지워집니다.
3. **알림음**: 기본 "딩동". 설정에서 내 파일로 바꿀 수 있습니다. 도배가 와도 0.8초에 한 번만 울립니다.

### 4-3. 불린 대화 목록

* 최대 **30개**까지 저장되고 새로고침해도 남습니다. 다른 채널로 이동하면 목록이 비워집니다.
* 오래된 것이 위, 최신이 아래입니다. 한 줄에 **시간(작게) → 닉네임 + 본문**이 쌓이고 본문 속 호출 단어는 노란색입니다.
* 항목을 누르면 해당 채팅으로 이동하고 노란색으로 반짝입니다. 원본이 사라졌으면 `사라짐`으로 표시합니다.
* **탭이 얼었다 깨어난 직후는 조용히**: 크롬이 백그라운드 탭을 절전으로 얼리거나 버렸다가 다시 살리면 채팅 화면이 새로 그려지면서 옛 호출이 다시 보일 수 있습니다. 앱이 이 순간(버려졌다 다시 불러옴, 얼었다 깨어남, 오래 가려졌다 다시 보임, 오래된 메시지가 한꺼번에 들어옴)을 알아채면 **그 직후 약 12초는 울리지 않고**, 불린 대화에 **같은 내용이 없을 때만 목록에 추가**합니다. 방송을 처음 열거나 채팅 영역이 다시 만들어질 때 이미 있던 채팅도 같은 방식으로 처리합니다.
* **재알림 방지**: 이미 울린 대화는 스크롤하거나 채팅창을 접었다 펴도, 소켓이 다시 연결돼도 다시 울리지 않습니다.

### 4-4. 드롭스

* 방송에 드롭스가 걸려 있으면 주황 창이 나옵니다. **없으면 창이 알아서 사라지고**, 1분마다 다시 확인합니다.
* 창에는 **아직 시간이 안 찬 다음 보상**의 이름과 이미지가 나오고, 그 아래에 `시청 54분 / 60분`처럼 표시됩니다.
* 시청 시간은 **치지직 서버가 세는 내 시청 시간**을 씁니다. (로그인 필수, 서버 값은 분 단위, 최대 1분 늦게 갱신)
* 보상 시간이 차면 **안내문 + 알림 + 소리 + (TTS를 켜면) 음성**으로 알려주고, 창이 **다음 보상**으로 바뀝니다.
  마지막 보상까지 다 찼으면 `시간충족`이라고 표시됩니다.
* 버튼: **새로고침🔄**(바로 다시 확인) / **보관함📦**(`game.naver.com` 드롭스 보관함 열기).

### 4-5. 확장(플러그인)

* **TTS**: 호출·드롭스·우두머리 알림을 음성으로 읽어줍니다. (브라우저 음성 합성 사용)
* **검은사막**
  * 우두머리가 나오기 **N분 전**부터 출현 시각까지 **주황색 알림 띠**가 화면 위에 계속 떠 있습니다. 남은 시간이 실시간으로 줄어듭니다.
  * 파랑 **"다음 우두머리" 창**이 다음 출현 시각과 남은 시간을 보여줍니다.
  * 보라색 **"쿠폰 모아보기" 창**: 검은사막 공식 "[GM노트] 쿠폰 모두 모아보기" 글의 쿠폰(이름, 코드, 보상, 유효 기간)을 보여줍니다. 쿠폰 이름, 코드, **만료일**만 보여주고, 코드 옆 **복사 아이콘**을 누르면 복사됩니다. 기간이 지난 쿠폰은 자동으로 숨깁니다.
    * 앱이 켜질 때 한 번 불러오고, **1시간마다 자동으로** 다시 불러옵니다. 창의 **새로고침(↻)** 으로 바로 불러올 수도 있습니다. ▾/▸ 로 접고 펼 수 있습니다.
    * 검은사막 사이트는 치지직 페이지에서 직접 읽을 수 없어서, 저장소의 `coupons.json`을 불러옵니다. 이 파일은 `scripts/crawl-coupons.js`가 해당 글을 읽어 갱신합니다(GitHub Actions가 1시간마다 실행, 부록 D 참고). 그래서 새 쿠폰이 반영되기까지 시간이 걸릴 수 있습니다.
  * 분홍색 **"가문검색" 창**: 입력칸에 가문명·길드명을 쓰고 검색하면 오른쪽 별도 창에 목록이 나옵니다. 가문: 캐릭터 목록(이름 · 직업 · 레벨), 길드: 길드원 목록(가문명 · 직위). 레벨 비공개 캐릭터는 `비공개`로 표시됩니다. 미리 등록된 가문·길드만 나오고(`data/adventure-targets.json`, `data/guild-targets.json`), 저장소의 `adventurers.json`·`guilds.json`을 1시간마다 받아옵니다. 없는 경우 GitHub Issues로 등록 요청하세요.
  * 시간표는 게임 공식 위키(<https://www.kr.playblackdesert.com/ko-kr/Wiki?wikiNo=167>)의 이미지를 보고 옮겨 적은 값이고, 저장소의 `bosses.json`에서 **6시간마다** 받아옵니다(받지 못하면 코드에 들어 있는 기본값 사용). 그래서 시간표가 바뀌어도 앱 업데이트 없이 파일만 고치면 반영됩니다.
    위키의 시간표는 글자가 아니라 이미지라서 자동으로 읽을 수 없습니다. 대신 **매주 수요일 18:00(한국시간)** 에 GitHub이 이미지가 바뀌었는지 확인하고, 바뀌었으면 새 이미지를 저장한 뒤 Issue로 알려 줍니다. 그러면 이미지를 보고 `bosses.json`을 고칩니다.
* 사용자 스크립트 허용(1단계 2번)이 꺼져 있으면 확장은 동작하지 않습니다.

### 4-6. 자동 시작 · 로그인 · 인가 채널

* **자동 시작**: 방송에 들어가면 `켤까요?`라고 묻거나(꺼짐일 때), 자동으로 바로 시작합니다(기본).
* **로그인 확인**: 치지직에 로그인되어 있지 않으면 프로그램이 **아예 실행되지 않고**, 1분마다 다시 확인합니다.
* **인가 채널**: `allowlist.json`에 등록된 채널에서만 동작합니다. 등록되지 않은 채널에서는 `인가되지 않은 채널입니다`라는 안내가 뜬 뒤
* **채널 사용 기간(만료)**: `allowlist.json`의 채널 항목에 `"expires": "2027-12-31"`(한국시간 그날 끝까지)처럼 만료일을 적을 수 있습니다. 만료일이 지나면 녹색 창에 **"⚠ 만료 경고"** 줄과 안내문(1시간에 한 번)이 뜨고, **만료일 + 3일이 지나면 동작하지 않습니다**(안내문 후 앱이 멈춤). `expires`를 **비워 두거나(`""`) 지우면 무기한**이고, 날짜 형식이 틀리면 무시(무기한)됩니다. 기준은 이 컴퓨터의 시계입니다.
  5초 뒤 화면의 창들이 사라집니다. 목록은 10분마다 다시 확인하고, 빠지면 감시가 멈춥니다.
  * 오프라인이면 마지막으로 받은 목록을 쓰고, 그것도 없으면 이번만 허용합니다.

### 4-7. 제한 모드 경고

2단계 "사용자 스크립트 허용"이 꺼져 있으면 초록 창에 노란 경고가 뜹니다.
이 상태에서는 화면(DOM) 감시만 되므로 **채팅창을 접으면 감지가 끊길 수 있습니다.** 허용을 켜고 새로고침하면 경고가 사라집니다.

## 5. 채널 추가 요청

1. GitHub 리포지토리 → **Issues** → **New issue**.
2. 제목은 `[채널 추가 요청] 채널명` 형식으로 씁니다.
3. 본문에 아래를 적습니다.
   * 방송 주소 (예: `https://chzzk.naver.com/live/xxxxxxxx`)
   * 채널 ID (주소의 `/live/` 뒤 32자리. 모르면 주소만 적어도 됩니다)
   * 채널명 (방송 화면에 보이는 그대로)
   * 디스코드 초대 주소, 채널 홈 주소 (버튼으로 달아줍니다. 없으면 생략)
   * 요청 사유 한 줄
4. 등록되면 `allowlist.json`에 채널이 추가되고, 보통 **수 분~1시간 안에** 적용됩니다.
   (목록은 1시간 단위로 받고 방송 중에도 10분마다 확인하므로, 바로 안 되면 새로고침해 보세요.)

| 설치 링크를 눌렀는데 글자만 보임 | Tampermonkey가 설치되지 않았거나(1단계) 꺼져 있습니다. 아이콘이 보이는지 확인 |

## 부록 B. 업데이트 하는 법

* **자동**: Tampermonkey가 하루에 한 번 새 버전이 있는지 확인해서 올라가면 갱신합니다.
* **바로 확인(권장)**: 설정 ⚙ → **앱 정보** → 🔄(업데이트 확인) 버튼.
  새 버전이 있으면 파란 **`업데이트`** 버튼이 켜집니다. 누르면 Tampermonkey 설치 화면이 열리고,
  `재설치/업그레이드`를 누르면 됩니다. (앱 화면 위에 안내 팝업이 뜨고, 설치 창을 닫으면 17초 뒤 자동으로 새로고침됩니다. 새로고침 직전에 불린 대화 목록이 비워지고 알람이 한 번 초기화될 수 있습니다.)
* 확장(플러그인)과 채널 목록은 **프로그램 업데이트와 별개로** 인터넷에서 받아오므로, 바뀐 뒤 최대 1시간 정도 지나서 반영될 수 있습니다.
* 업데이트 후에는 방송 페이지를 새로고침해야 적용됩니다.

## 부록 C. 확장(플러그인) 만들기

* `plugins.json`에 등록된 확장을 방송 진입 시 자동으로 불러옵니다. 사용자는 설정 > **확장**에서 켜고 끕니다.
* 채널 항목(`allowlist.json`)에 `plugins`가 있으면 그 목록·기본값(`on`, `options`)으로 확장 메뉴를 구성합니다. 우선순위는 사용자 선택 > 채널 > 매니페스트입니다. `plugins`가 없는 채널은 전역 동작합니다.
* 만들기
  1. `plugins/` 아래에 `.js` 파일을 추가합니다. 이벤트를 받으려면 `window.__KW.on('hit', ({nick, text, kw}) => {...})`.
     * 이벤트: `hit`(호출), `drops`(드롭스 시간 충족), `ext:이름`(확장끼리 주고받는 이벤트, `window.__KW.emit('이름', 데이터)`)
     * 도우미: `window.__KW.toast(닉네임, 본문)`, `window.__KW.sound()`(설정의 알림 소리 재생),
       `window.__KW.enabled('id')`(켜져 있는지), `window.__KW.option('id','키')`(옵션 값)
  2. `plugins.json`의 `plugins` 배열에 `{id, name, desc, url(Raw 주소), on, options}`를 추가합니다.
     * `options`: `[{key, label, type: 'bool'|'number'|'multi', default, min, max, choices}]` 로 적으면 설정 화면에 입력칸이 자동으로 생깁니다.
  3. 별도 설치는 없습니다. 방송 페이지를 열면 시간 단위 캐시 후 자동으로 불러옵니다.
* 예시: `plugins/tts.js`(음성 안내), `plugins/blackdesert.js`(우두머리 알림).
* 제한: 사용자 스크립트 허용이 꺼진 환경에서는 확장이 동작하지 않습니다.

## 부록 D. 개발 (베타 작업 시)

* 베타는 얇은 로더(`beta/chzzk_alert.beta.user.js`)이고, 실제 코드는 `src/` 아래 4개 파일을 `@require`로 불러옵니다.

| 파일 | 내용 |
| --- | --- |
| `src/core.js` | 저장소·설정값, 진단 로그, 채팅 소켓 감시, 환경 판별, 상태, 스타일(CSS) |
| `src/chat.js` | 알림(토스트·소리·브라우저 알림), 불린 대화, 채팅 감시, 인가 채널 |
| `src/ui.js` | 패널·설정 화면·드롭스 창·드래그 조절·업데이트 팝업 |
| `src/app.js` | 화면 전환 감지, 플러그인 로딩, 로그인 확인, 시작 |

* 빌드: **`node src/build.js`** → 헤더(`src/header.txt`)의 `@version`을 읽어 로더를 만들고 `core.js`의 버전과 `@require` 주소의 `?v=`를 맞춥니다.
* **코드를 바꿀 때마다 `src/header.txt`의 `@version`을 올리고 빌드한 뒤 커밋**합니다. 같은 버전을 다시 올리면 Tampermonkey가 모듈을 새로 받지 않습니다.
* 버전은 `메이저.마이너.패치` 3자리(예: `3.1.0`)입니다. **베타는 끝자리 대신 `-betaNN`만 올립니다**(`3.1.0-beta67` → `3.1.0-beta68`).
  기준 버전(`3.1.0`)이 바뀌면 베타 번호는 `001`부터 다시 누적합니다(`3.2.0-beta001`). 정식 릴리즈 때 접미사를 떼서 `3.1.0`으로 냅니다. 정식 이후의 수정은 패치(`3.1.1`), 기능 추가는 마이너(`3.2.0`), 호환이 깨지면 메이저(`4.0.0`)를 올립니다.
* 새 모듈 파일을 추가하면 `src/build.js`의 `MODULES`에도 넣어야 합니다.
* **정식 릴리즈**: `node src/build.js --release 3.2.0` → 정식도 베타처럼 **얇은 로더**이고, 코드는 **난독화**해서 `release/`에 둡니다.
  * 루트 `chzzk_alert.user.js`: 헤더 + `@require`(`release/*.js?v=버전`)만 있는 로더. 직접 고치지 않습니다.
  * `release/core.js`, `chat.js`, `ui.js`, `app.js`: `src/`를 정식용으로 변환하고 난독화한 **고정 사본**입니다.
    `release/plugins.json`, `release/plugins/*.js`: 정식용 확장 목록과 난독화한 확장 코드입니다. 정식 앱은 이쪽만 불러옵니다.
  * 정식 릴리즈 때만 다시 만들어지므로 베타 개발(`src/`, `plugins/`)이 정식에 섞이지 않습니다.
  * 변환 내용: `[BETA-TEST-ONLY:start]`~`[BETA-TEST-ONLY:end]` 구간(테스트 버튼, `__kwDebug`, `dropsSimMin`, 확장의 테스트 후크)과 `[BETA-ONLY-LINE]` 줄 제거, 콘솔 로그·하트비트 끄기, 업데이트/확장 주소를 정식용으로 교체. 결과에 베타 흔적이 남으면 빌드가 실패합니다.
    베타 전용 코드를 새로 넣을 때는 반드시 위 표식으로 감싸세요.
  * **난독화**: `javascript-obfuscator`(개발용 의존성). 먼저 `npm install`이 필요합니다. 모듈들이 최상위 함수·변수 이름을 서로 공유하므로 최상위 이름은 바꾸지 않고(`renameGlobals: false`),
    문자열(RC4)·지역 이름·제어 흐름·죽은 코드 삽입 등을 적용합니다. 결과는 원본보다 훨씬 커집니다(약 100KB → 1.2MB). 디버깅용으로 `--no-obfuscate`를 줄 수 있지만 그 결과는 배포하지 않습니다.
* **쿠폰 크롤러**: `node scripts/crawl-coupons.js`가 검은사막 쿠폰 글을 읽어 `coupons.json`을 만듭니다. `.github/workflows/crawl-coupons.yml`이 1시간마다 실행해서 바뀐 경우에만 커밋합니다(수동 실행도 가능). 읽기에 실패하거나 쿠폰이 하나도 없으면 기존 파일을 그대로 둡니다.
