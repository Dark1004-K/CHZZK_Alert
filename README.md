# 치지직 채팅 호출 알림 (CHZZK Keyword Alert)

> **업데이트 내용 보러가기 → [UPDATE.md](./UPDATE.md)**

치지직(CHZZK) 생방송 채팅에서 등록한 단어(닉네임 등)가 언급되면
브라우저 알림 + 화면 토스트 + 알림음으로 알려주는 Tampermonkey 사용자 스크립트.

---

## 1. 처음 설치

### 1.1 Tampermonkey 설치

1. 쓰는 브라우저의 확장 스토어에서 Tampermonkey를 설치한다.
   * Chrome: [Chrome 웹스토어에서 설치](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   * Edge: [Edge 추가 기능에서 설치](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
   * Whale: 웨일 스토어에서 `Tampermonkey`를 검색해서 설치한다.
2. 설치 후 툴바에 Tampermonkey 아이콘이 뜨는지 확인한다.
   안 보이면 브라우저의 확장(퍼즐 조각) 메뉴 → Tampermonkey 옆 핀을 눌러 툴바에 고정한다.
3. 아이콘을 눌렀을 때 `사용 가능` 상태로 뜨면 설치 완료다.
   (이 리포지토리의 스크립트는 설치 후에 1.3/1.4 순서대로 넣는다.)

### 1.2 사용자 스크립트 허용 켜기 (필수)

이 스크립트는 채팅 소켓을 직접 가로채는 방식(WS 스니핑)을 쓴다.
이 방식은 Tampermonkey가 **페이지 컨텍스트에서 실행될 때만** 동작하고,
그 실행에는 브라우저의 **사용자 스크립트 허용**이 필요하다.

1. `chrome://extensions` 로 이동한다.
2. Tampermonkey 카드에서 **세부정보**를 연다.
3. **사용자 스크립트 허용** 토글을 켠다.
4. 방송 페이지를 새로고침한다. (`document-start` 후킹이라 로드 이후 설치/업데이트는 반드시 새로고침해야 적용됨)

**안 켜면 어떻게 되나?**

* 감지 자체는 된다. 채팅 DOM 감시 경로는 격리 환경에서도 동작한다.
* 대신 WS 스니핑이 안 먹어서 **채팅창을 접어둔 상태의 감지가 끊길 수 있다.**
* 감시 패널에 노란 경고가 뜬다:
  `사용자 스크립트 허용 꺼짐: WS 감시 불가, DOM 감시만 동작.`
* 이 경고가 보이면 위 순서대로 켜고 새로고침하면 사라진다.

### 1.3 정식 설치

1. 아래 Raw URL을 브라우저 주소창에 붙여넣고 연다. (코드 블록 우상단 복사 버튼 이용)

```text
https://raw.githubusercontent.com/Dark1004-K/CHZZK_Alert/main/chzzk_alert.user.js
```

   (또는 Tampermonkey 대시보드 → Utilities → Install from URL에 붙여넣기)
2. Tampermonkey 설치 확인 화면에서 **설치**를 누른다.
3. 방송 페이지(`https://chzzk.naver.com/live/...`)를 새로고침한다.
4. 처음이면 `채팅 호출 알림을 켤까요?` 창이 뜬다. **켜기**를 누른다.
   (`다음부터 묻지 않고 자동으로 켜기`에 체크하면 다음부터 바로 켜짐)

### 1.4 베타 설치 (정식과 구분)

| 구분 | 정식 | 베타 |
| --- | --- | --- |
| 파일 | `chzzk_alert.user.js` (루트) | `beta/chzzk_alert.beta.user.js` |
| Raw URL | 위 1.3 정식 주소 | 아래 베타 주소 |

```text
https://raw.githubusercontent.com/Dark1004-K/CHZZK_Alert/main/beta/chzzk_alert.beta.user.js
```
| 스크립트 이름 | CHZZK 채팅 호출 알림 (Keyword Alert) | CHZZK 채팅 호출 알림 (Beta) |
| 자동 업데이트 | 버전 오르면 자동 (1일 1회 확인) | 버전 오르면 자동 (별개 채널) |
| 콘솔 로그 | 없음 | 진단 로그 있음 (`[KW-BETA]`) |

베타 이름에 `(Beta)`가 붙어 있어서 **정식과 나란히 설치된다.**

### 1.5 버전 전환 시 주의점

1. **둘 중 하나만 켜기.** 정식과 베타를 동시에 켜두면 같은 채팅을 두 번 감지해서
   알림·소리가 중복으로 울린다. 안 쓰는 쪽은 Tampermonkey 대시보드에서 끈다.
2. **설정은 공유된다.** 단어·닉네임·불린 대화 기록은 브라우저 저장소(같은 키)를 쓰므로
   정식↔베타를 옮겨도 설정이 그대로 따라간다. 반대로 말하면 한쪽에서 지우면 양쪽에서 지워진다.
3. **재설치(또는 업데이트 확인)가 필요한 경우.**
   `@match`가 바뀌는 업데이트(예: 감시 채널 범위 변경)는 설치된 스크립트의 실행 대상에 바로 반영되지 않는다.
   이럴 땐 Raw URL로 다시 설치하거나, Tampermonkey 대시보드에서 해당 스크립트의 업데이트 확인을 눌러준다.
4. **구버전으로 내리기.** 낮은 버전을 위에 설치하면 Tampermonkey가 경고를 띄울 수 있다.
   안내에 따라 확인하거나, 기존 것을 지우고 다시 설치한다.
5. **설치·업데이트 후에는 방송 페이지를 반드시 새로고침한다.**
   소켓 후킹이 페이지 로드 시점에 걸리므로, 새로고침 전에는 WS 감시가 안 잡힌다.
6. **소리는 첫 클릭 이후에 난다.** 브라우저 자동재생 정책 때문에, 페이지에서 한 번이라도
   클릭/키 입력이 있어야 오디오가 깨워진다. 스크립트가 첫 제스처를 감지하면 자동으로 깨우므로
   따로 설정할 것은 없고, 설치 직후 무음이면 화면을 한 번 클릭해보면 된다.

### 1.6 업데이트 확인

* 자동: Tampermonkey가 1일 1회 Raw를 확인해서 `@version`이 오르면 갱신한다.
* 수동: Tampermonkey 대시보드에서 스크립트 선택 → 업데이트 확인(또는 강제 업데이트 확인).
  또는 설정 → 앱 정보 탭의 🔄 확인 후 ⬇️ 업데이트 버튼.
* 업데이트 후에도 방송 페이지는 새로고침해야 적용된다.

### 1.7 플러그인

* `plugins.json`에 등록된 플러그인을 방송 진입 시 자동으로 불러온다. (베타만)
* 플러그인 만들기:
  1. `plugins/` 아래에 `.js` 파일 추가.
     `window.__KW.on('hit', ({nick, text, kw}) => {...})` 형태로 구독.
     (`window.__KW.toast(nick, body)`로 토스트도 쏠 수 있음)
  2. `plugins.json`의 `plugins` 배열에 `{id, name, url(Raw 주소), on}` 추가.
  3. 별도 설치 없음. 시간 단위 캐시 이후 자동 로딩.
* 예시: `plugins/tts.js` (누가 불렀는지 음성 안내).
* 제한: 사용자 스크립트 허용이 꺼진 격리 환경에서는 플러그인이 안 뜬다.

## 개발 (베타 작업 시)

* 본체는 `src/` 모듈로 나눠져 있다. 직접 고치지 말고 모듈을 고친 뒤 빌드:
  `node src/build.js` → `beta/chzzk_alert.beta.user.js` 재생성.
* 빌드 후 하네스로 검증하고 커밋한다. (`src/` + 빌드 결과물 함께 커밋)
* 정식(`chzzk_alert.user.js`)은 릴리즈 때만 베타 내용으로 갈아엎는다.

## 2. 기능 설명

### 2.1 감지 규칙

* 등록한 단어가 채팅에 나오면 감지한다. 대소문자 무시, 띄어쓰기 차이는 흡수한다.
* **단어 경계 보호:** `데아`를 등록했을 때 `그런데 아~~`처럼 띄어쓰기 경계를 넘어 합쳐지는 경우는 제외한다.
  같은 어절 안에 붙어 있는 경우(`데아님`, `데아!`)는 감지한다.
* **내 채팅 제외:** `내 닉네임`에 적은 이름으로 쓴 내 채팅은 알림에서 뺀다.
  남이 내 닉네임을 부른 것은 정상 감지한다.

### 2.2 알림 3종

1. **브라우저 시스템 알림.** 제목에 부른 사람 닉네임, 본문에 대화 내용이 분리되어 뜬다.
   직접 닫을 때까지 유지되고, 클릭하면 방송 창으로 포커스가 돌아온다.
   (다른 탭을 보고 있어도 놓치지 않게 하기 위함)
2. **화면 토스트.** 불린 대화 목록 바로 위에 같은 너비로 떴다가 5초 뒤 사라진다.
   한 줄 표시(굵은 닉네임 + 본문), 길면 말줄임. 클릭하면 바로 지워진다.
3. **알림음.** 짧게 두 번 울린다. 도배 때는 0.8초에 한 번으로 솎아낸다.

### 2.3 불린 대화 목록

* 감지된 대화를 최대 30개까지 저장한다. 새로고침해도 남는다.
* 항목은 `시간 굵은닉네임 본문` 형태이고, 본문 속 검출 단어는 노란색으로 표시된다.
* 항목을 클릭하면 해당 채팅 위치로 스크롤 + 노란 하이라이트.
  원본이 목록에서 밀려나도 같은 내용을 찾아서 이동해주고,
  진짜 사라졌으면 목록에서 빼고 `이미 사라진 대화입니다`라고 알려준다.
* **재알림 방지:** 이미 울린 대화(목록에 있는 것과 같은 내용)는
  스크롤 백필·채팅창 접기/펼치기·소켓 재접속으로 다시 보여도 울리지 않는다.
  설정의 체크박스를 끄면 이 재알림 방지도 같이 꺼진다.

### 2.4 화면 구성

왼쪽 아래에 위에서부터 쌓인다. 전체 너비는 기본 350px.

1. **알람 토스트 자리** (뜰 때만 보임)
2. **불린 대화** (노란 테두리) — 개수 + 지우기
3. **감시중/중지됨** (초록 테두리) — 단어 수, 감지 횟수, 설정·정지 버튼
4. **설정** (회색 테두리, 감시 패널 오른쪽) — 설정 버튼으로 여닫이, 열림 상태 저장됨

* 감시 패널 오른쪽 가장자리를 드래그하면 전체 너비가 늘고 줄고, 위에 있는 창들이 같이 따라간다. (240~600px, 저장됨)
* 설정 화면은 왼쪽 탭으로 나뉜다.
  * **일반설정:** 자동 켜기, 불린 대화 목록 표시 여부.
  * **단어설정:** 호출 단어 칩(×로 삭제), 추가 입력, 내 닉네임.

### 2.5 단어 관리

* 설정 → 단어설정에서 직접 추가하거나, 방송 페이지 글자를 드래그하면 뜨는
  `＋ 호출 단어로 추가` 버튼으로 추가한다. (30자 이하, 한 줄만)
* 페이지 글자를 드래그할 때마다 뜨는 버튼이 거슬리면 무시하면 된다. (선택해야만 등록됨)

### 2.6 자동 시작

* 방송에 들어가면 `채팅 호출 알림을 켤까요?`라고 묻는다.
* `다음부터 묻지 않고 자동으로 켜기`에 체크하면 다음부터 바로 감시 시작.

### 2.7 인가 채널

* `allowlist.json`에 등록된 채널 ID의 방송에서만 동작한다.
* 미등록 채널에서는 `인가되지 않은 채널입니다` 토스트 후 감시를 시작하지 않는다.
* 목록은 실행 시 내려받고 10분마다 조용히 재확인한다. 목록에서 빠지면 감시가 멈춘다.
* 오프라인이면 마지막 캐시를 쓰고, 캐시도 없으면 이번만 허용한다.
* 참고: 이 검사는 사용자 PC에서 도는 것이라 강제력은 없다. (관리용 + 원격 스위치)

### 2.8 제한 모드 경고

1.2의 허용이 꺼져 있으면 감시 패널에 노란 경고가 뜬다.
이 상태에서는 DOM 감시만 되므로 채팅창을 접으면 감지가 끊길 수 있다.

## 3. 채널 추가 개설 요청법

1. GitHub 리포지토리 → Issues → New issue.
2. 제목은 `[채널 추가 요청] 채널명` 형식으로 쓴다.
3. 본문에 아래를 적는다.
   * 방송 URL (예: `https://chzzk.naver.com/live/xxxxxxxx`)
   * 채널 ID (URL의 `/live/` 뒤 32자리. 모르면 URL만 적어도 됨)
   * 채널명 (방송 화면에 보이는 그대로)
   * 디스코드 초대 URL, 채널 홈 URL (버튼으로 달아줌. 없으면 생략)
   * 요청 사유 한 줄
4. 등록되면 `allowlist.json`에 채널 ID가 추가되고, 빠르면 수 분 안에 적용된다.
   (목록은 1시간 단위로 묶어서 내려받고 방송 중에도 10분마다 재확인하므로,
   바로 안 되면 페이지를 새로고침해본다.)

## 4. 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 감지 자체가 안 됨 | 패널이 `감시중`인지, 단어가 등록됐는지, 인가 채널인지(`인가되지 않은 채널입니다` 토스트 여부) |
| 채팅창 접으면 안 잡힘 | 1.2 허용이 켜져 있는지 (경고 배너 확인). 허용 없이 WS 감시가 안 됨 |
| 소리가 안 남 | 페이지에서 한 번 클릭했는지 (자동재생 정책). 볼륨·탭 음소거 확인 |
| 다른 탭에서 알림을 놓침 | v2.8+는 유지형 알림. 그래도 못 받으면 브라우저 OS 알림 권한(방해 금지 모드 등) 확인 |
| 알림이 두 번 울림 | 정식+베타 동시 실행 중인지. 하나만 켜기 (1.5-1) |
| 업데이트했는데 그대로 | 방송 페이지 새로고침 여부. `@match` 변경분은 재설치 필요 (1.5-3) |
| 목록 클릭이 안 감 | 원본이 밀려나면 자동 정리됨. `이미 사라진 대화입니다`가 뜨면 정상 동작 |
