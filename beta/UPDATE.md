# UPDATE (베타) — 베타 변경 이력

베타(`beta/`) 변경은 **이 파일에만** 기록한다. 정식 변경은 루트의 [UPDATE.md](../UPDATE.md)에 기록한다.
`@version`이 오르면 Tampermonkey가 자동 갱신한다. (기본 1일 1회 확인)
버전은 `메이저.마이너.패치` 3자리이고, **베타는 끝자리를 올리지 않고 `-betaNN`만 올린다.** (예: `3.1.0-beta67` → `3.1.0-beta68`)
**기준 버전(`3.1.0` 부분)이 바뀌면 베타 번호는 `001`부터 다시 시작해서 누적한다.** (예: `3.2.0-beta001` → `3.2.0-beta002`)
정식 릴리즈로 승격되면 접미사를 떼고(`3.1.0`) 요약을 루트 UPDATE.md로 옮긴다.

## v3.6.0-beta050

* **방송 중이 아닐 때도 실행(채널 페이지)**: 채널 페이지(`chzzk.naver.com/채널ID`)에서도 감시 패널과 확장(플러그인)이 실행된다. `pageChannelId()`가 `/{채널ID}` 경로도 인식하도록 확장하고, 라이브 전용 동작(채팅 호출 프롬프트·채팅 감시 유도·드롭스 창·텍스트 선택 추가)은 `isLivePage()`(`/live/` 경로 전용)로 분리해 그대로 유지했다.
* **오프라인에서는 카테고리 조건 해제**: `live-detail`의 `status`가 `OPEN`이 아니면(방송 종료·방송 정보 없음·조회 실패) `requireCategory` 조건을 무시하고 **모든 확장 실행**. 채널 페이지에서도 5초 폴링으로 상태를 확인하고, 라우트가 바뀔 때·인가가 확인될 때는 즉시 확인해 늦게 바뀌는 것을 막는다.
* **채널 페이지 인가 판정**: 등록명 대조는 라이브 페이지에서만 수행한다 — 채널 페이지는 탭 제목·링크로 표시명을 안정적으로 읽을 수 없어 ID로만 인가 (라이브에서 통과한 동일 항목이므로 안전, 기존 "페이지명을 못 읽으면 ID만으로 허용" 방침과 같다).
* **채널 페이지에서는 프롬프트·드롭스 감춤**: 채팅 호출 프롬프트(자동 감시 포함)와 드롭스 창은 라이브에서만 뜬다. 감시 시작은 감시 패널 버튼으로 가능하고, 라이브 진입 시에는 기존처럼 프롬프트가 나온다.

## v3.6.0-beta049

* **방송 카테고리 자동 조건부 확장(`requireCategory`)**: `plugins.json`의 확장에 `requireCategory: ["검은사막"]` 같은 문자열 배열을 넣으면, 방송 카테고리가 목록과 맞는 동안에만 실행된다 (부분 일치·대소문자 무관). `live-detail` API를 5초마다 읽어 카테고리가 다른 게임(예: 붉은사막)으로 바뀌면 해당 확장이 **자동으로 꺼지고**, 다시 돌아오면 **자동으로 켜진다** — 사용자 on/off 저장값은 건드리지 않는다. 진입 시에는 첫 주입 전에 카테고리를 먼저 확인해서 켜졌다가 몇 초 뒤 꺼지는 깜빡임도 막는다.
* **확장 목록에 자동 꺼짐 안내**: 조건 미충족 동안 설정 > 확장에서 해당 확장 옆에 노란색 "(카테고리 조건 미충족 · 현재: 붉은사막 → 자동 꺼짐)" 표시. 체크박스는 사용자 의지 그대로 보여주어 조건이 돌아오면 그대로 실행된다.
* **새 API**: `window.__KW.category()`로 현재 방송 카테고리(`{value, name, status}`) 확인 가능, `KW.on('category', fn)`으로 변경 알림 구독 가능.
* **동시 주입 방지**: 플러그인 주입 요청이 진행 중일 때 중복 주입하지 않도록 보강 (`pluginLoading`).
