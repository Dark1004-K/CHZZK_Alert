# UPDATE (베타) — 베타 변경 이력

베타(`beta/`) 변경은 **이 파일에만** 기록한다. 정식 변경은 루트의 [UPDATE.md](../UPDATE.md)에 기록한다.
`@version`이 오르면 Tampermonkey가 자동 갱신한다. (기본 1일 1회 확인)
버전은 `메이저.마이너.패치` 3자리이고, **베타는 끝자리를 올리지 않고 `-betaNN`만 올린다.** (예: `3.1.0-beta67` → `3.1.0-beta68`)
**기준 버전(`3.1.0` 부분)이 바뀌면 베타 번호는 `001`부터 다시 시작해서 누적한다.** (예: `3.2.0-beta001` → `3.2.0-beta002`)
정식 릴리즈로 승격되면 접미사를 떼고(`3.1.0`) 요약을 루트 UPDATE.md로 옮긴다.

## v3.4.0-beta009
