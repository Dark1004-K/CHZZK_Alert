# UPDATE (베타) — 베타 변경 이력

베타(`beta/`) 변경은 **이 파일에만** 기록한다. 정식 변경은 루트의 [UPDATE.md](../UPDATE.md)에 기록한다.
`@version`이 오르면 Tampermonkey가 자동 갱신한다. (기본 1일 1회 확인)
버전은 `메이저.마이너.패치` 3자리이고, **베타는 끝자리를 올리지 않고 `-betaNN`만 올린다.** (예: `3.1.0-beta67` → `3.1.0-beta68`)
정식 릴리즈로 승격되면 접미사를 떼고(`3.1.0`) 요약을 루트 UPDATE.md로 옮긴다.

## v3.1.0-beta67

* 버전 표기: 베타는 `메이저.마이너.패치-betaNN` 형식을 쓴다. 정식 후보 번호(`3.1.0`)는 고정하고 `-betaNN`만 올린다.
  기존 설치분(`3.0.x`)에서도 자동 업데이트되도록 `3.0.2`보다 높은 `3.1.0`을 정식 후보로 잡았다.
* 업데이트 노트 분리: 베타 변경은 `beta/UPDATE.md`(이 파일)에만, 루트 `UPDATE.md`는 정식 변경만 기록.
  앱 정보의 "업데이트 내용" 링크는 이 파일을 가리킴.

## v3.0.1 (베타)

* 설정 > 확장: 제목을 "확장 모듈 설정(체크하면 켜짐)"으로, 항목 이름을 "TTS 활성", "검은사막 확장 활성"으로 줄임.
* 확장 옵션은 해당 확장을 체크했을 때만 보이고, 끄면 사라짐.
* 앱 정보의 "업데이트 내용" 링크가 `beta/UPDATE.md`를 가리킴.

## v3.0.0 (베타)

버전 표기를 `메이저.마이너.패치` 3자리로 바꿨다. (이전 `2.8-betaNN`보다 높아서 기존 설치분에서도 자동 업데이트됨)
v2.8-beta30 이후 변경을 한꺼번에 정리한다.

* 구조: 베타는 얇은 로더(`@require`)이고 코드는 `src/core.js`, `chat.js`, `ui.js`, `app.js` 4개로 합쳤다.
* 치지직 **로그인 필수**: 로그인이 안 되어 있으면 앱을 실행하지 않고 1분마다 재확인.
* **드롭스 창**(주황): 치지직 서버가 집계한 내 시청 분 표시, 다음 보상 전환, 시간 충족 알림(안내문·소리·TTS),
  새로고침🔄·보관함📦 버튼, 드롭스가 없으면 창 자동 제거, 설정에서 끄기.
* **확장 탭**: 플러그인 켜기/끄기와 플러그인별 옵션. 플러그인 간 이벤트(`ext:`)·`__KW.sound()` 제공.
* **검은사막 확장**: 우두머리 출현 N분 전 주황 알림(출현까지 유지), 파란 "다음 우두머리" 창, 알림 TTS, 옵션(분 전/알림음/우두머리 선택).
* **알림 소리**: 딩동(기본) / 내 파일. 브라우저 알림은 무음으로 띄워 윈도우 알림음과 겹치지 않게 함.
* 일반설정: 기본값을 알람 끄기만 빼고 모두 켜짐으로, "같은 호출 다시 울리기"를 초 단위(기본 5초)로,
  "재알림 방지"를 끄면 숫자 입력 불가.
* 불린 대화: 오래된 것이 위·최신이 아래, 시간은 닉네임 위에 작게, 높이 드래그 조절(80px~화면 85%), 다른 채널로 가면 초기화.
* 창 크기: 너비 최소 216px, 드래그 가능한 곳에 막대 표시.
* 미인가 채널: 토스트가 끝나면 감시를 멈추고 화면의 창을 제거.
* 업데이트 버튼: Tampermonkey 설치 안내 팝업을 앱 화면 위에 띄우고, 설치 창이 닫히면 7초 뒤 자동 새로고침.
* 버전 규칙: 코드를 바꿀 때마다 `src/header.txt`의 `@version`을 올린다. 기본은 패치(+0.0.1), 기능 추가는 마이너, 호환이 깨지면 메이저.
